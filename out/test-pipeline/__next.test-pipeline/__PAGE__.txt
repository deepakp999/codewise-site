</div><h2 id="the-big-picture">The Big Picture</h2>
<p>Apache Spark is an <strong>open-source, distributed computing engine</strong> designed to process large datasets across a cluster of machines. Think of it as a supercharged data processing engine that can handle terabytes (or even petabytes) of data.</p>
<p>Before Spark, the go-to tool for big data was <strong>MapReduce</strong> (part of Hadoop). MapReduce worked, but it was painfully slow because it wrote intermediate results to disk after every step.</p>
<p>Spark changed the game by keeping data <strong>in memory</strong> between processing steps — making it up to <strong>100x faster</strong> than MapReduce for certain workloads.</p>

<h2 id="when-to-use-spark">When to Use Spark</h2>
<p>Spark shines when you need to:</p>
<ol>
<li><strong>Process datasets that don't fit in memory</strong> on a single machine</li>
<li><strong>Run complex analytics</strong> (aggregations, joins, ML pipelines) on large data</li>
<li><strong>Build ETL pipelines</strong> that transform data from multiple sources</li>
<li><strong>Stream real-time data</strong> from Kafka, Kinesis, or other sources</li>
</ol>
<p>If your data fits comfortably in a Pandas DataFrame (under ~10GB), you probably don't need Spark yet. We'll cover this comparison in detail in the next lesson.</p>
<h2 id="how-spark-works-simplified">How Spark Works (Simplified)</h2>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">graph LR</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    A[Driver Program] --> B[Cluster Manager]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    B --> C[Worker Node 1]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    B --> D[Worker Node 2]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    B --> E[Worker Node 3]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    C --> F[Executor]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    D --> G[Executor]</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    E --> H[Executor]</span></span></code></pre>
<p>The <strong>Driver</strong> is your main program. It sends tasks to <strong>Executors</strong> running on <strong>Worker Nodes</strong> across the cluster. The Cluster Manager (like YARN or Kubernetes) coordinates everything.</p>

<p>For now, all you need is Python and pip:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">pip</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> pyspark</span></span></code></pre>
<p>That's it. PySpark bundles a local Spark instance — no cluster needed for learning.</p>
<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Trying to learn Spark before Python.</strong> Spark's API is Python-based. If you're not comfortable with Python basics (lists, dicts, functions), learn those first.</li>
<li><strong>Using Spark for small datasets.</strong> Spark has startup overhead. For datasets under 1GB, Pandas is faster and simpler. Match the tool to the task.</li>
<li><strong>Ignoring the Spark UI.</strong> The web UI at <code>localhost:4040</code> shows exactly what Spark is doing. Always check it when things are slow.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Spark is a distributed computing engine for big data</li>
<li>It's up to 100x faster than MapReduce thanks to in-memory processing</li>
<li>PySpark lets you use Spark with Python</li>
<li>You don't need a cluster to learn — <code>pip install pyspark</code> is enough</li>
<li>Don't use Spark for small data — Pandas is better for that</li>
</ul>
