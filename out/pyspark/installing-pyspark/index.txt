<h3 id="colab-limitations">Colab Limitations</h3>
<p>Colab is great for learning but has limits:</p>

<h2 id="option-b-local-install">Option B: Local Install</h2>
<p>If you want PySpark on your own machine — for offline work, larger datasets, or production development — follow these steps.</p>
<h3 id="prerequisites">Prerequisites</h3>
<p>PySpark needs two things on your machine:</p>
<ol>
<li><strong>Python 3.9 or higher</strong> — you probably already have this</li>
<li><strong>Java 17 or 21</strong> — this is the part that trips up most people</li>
</ol>
<p>Let's check what you have and install what's missing.</p>
<h2 id="step-1-check-your-python-version">Step 1: Check Your Python Version</h2>
<p>Open a terminal (or Command Prompt on Windows) and run:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">python</span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66"> --version</span></span></code></pre>

<blockquote>
<p><strong>Note:</strong> On some systems, you may need to use <code>python3</code> instead of <code>python</code>.</p>
</blockquote>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>

<li><strong>Forgetting to restart the terminal after setting environment variables.</strong> After adding <code>JAVA_HOME</code> or modifying <code>PATH</code>, you must open a new terminal window (or run <code>source ~/.zshrc</code>) for the changes to take effect.</li>

</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>PySpark requires Python 3.9+ and Java 17 or 21.</li>
<li>Install with <code>pip install pyspark</code> — it includes a built-in standalone Spark for local development.</li>
<li>The most common installation issue is Java not being installed or <code>JAVA_HOME</code> not being set.</li>
<li>Set the log level to <code>ERROR</code> or <code>WARN</code> to reduce console noise while learning.</li>
</ul>
