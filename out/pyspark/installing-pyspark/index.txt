19:T3e99,<h1 id="installing-pyspark">Installing PySpark</h1>
<div data-cw-section="learn-box"><h2 id="what-youll-learn">What You'll Learn</h2>
<ul>
<li>How to install Java (Spark's runtime dependency)</li>
<li>How to install PySpark with pip</li>
<li>How to verify your installation works</li>
<li>How to troubleshoot common installation issues</li>
</ul>
</div><h2 id="prerequisites">Prerequisites</h2>
<p>Before installing PySpark, you need:</p>
<ol>
<li><strong>Python 3.8+</strong> installed</li>
<li><strong>Java 11 or 17</strong> (Spark runs on the JVM)</li>
<li><strong>pip</strong> (Python's package manager)</li>
</ol>
<h2 id="step-1-install-java">Step 1: Install Java</h2>
<p>Spark runs on the Java Virtual Machine (JVM), so you need Java installed first.</p>
<h3 id="check-if-java-is-already-installed">Check if Java is already installed</h3>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">java</span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66"> -version</span></span></code></pre>
<div data-cw-section="output-block"><h3 id="expected-output">Expected Output</h3>
<pre data-cw-output="true"><code>openjdk version "17.0.2" 2022-01-18
OpenJDK Runtime Environment (build 17.0.2+8-86)
OpenJDK 64-Bit Server VM (build 17.0.2+8-86, mixed mode, sharing)
</code></pre></div>
<p>If you see a version number (11+), you're good. If not, install it:</p>
<h3 id="macos">macOS</h3>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">brew</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> openjdk@17</span></span></code></pre>
<h3 id="ubuntudebian">Ubuntu/Debian</h3>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">sudo</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> apt</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> update</span></span>
<span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">sudo</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> apt</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> openjdk-17-jdk</span></span></code></pre>
<h3 id="windows">Windows</h3>
<p>Download from <a href="https://adoptium.net/">Adoptium</a> and run the installer. Make sure to check "Set JAVA_HOME" during installation.</p>
<h2 id="step-2-install-pyspark">Step 2: Install PySpark</h2>
<p>With Java ready, installing PySpark is one command:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">pip</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> pyspark</span></span></code></pre>
<p>This installs PySpark and bundles a local Spark instance — no cluster setup needed.</p>

<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF">pip</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> pyspark==</span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66">3.5.0</span></span></code></pre>

<h3 id="py4jjavaerror-on-startup">"Py4JJavaError" on startup</h3>
<p>This usually means Java version mismatch. Spark 3.5 supports Java 11 and 17. Java 8 works but is deprecated. Java 21 is <strong>not</strong> supported yet.</p>
<h3 id="slow-startup-on-first-run">Slow startup on first run</h3>
<p>The first time you create a SparkSession, Spark downloads some files and initializes. This can take 30-60 seconds. Subsequent runs are faster.</p>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Forgetting to install Java.</strong> PySpark will install fine with pip, but fail at runtime without Java. Always verify <code>java -version</code> first.</li>
<li><strong>Using Java 21.</strong> Spark 3.5 doesn't support Java 21 yet. Stick with Java 11 or 17.</li>
<li><strong>Installing in the wrong Python environment.</strong> If you use conda or venv, make sure PySpark is installed in the same environment you're running scripts from.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>PySpark needs Java 11 or 17 as a prerequisite</li>
<li><code>pip install pyspark</code> bundles everything you need for local development</li>
<li>Always verify with a simple DataFrame test after installation</li>
<li>First startup is slow; subsequent runs are faster</li>
<li>Set JAVA_HOME if you encounter Java-related errors</li>
</ul>
