</div><h2 id="what-is-a-sparksession">What is a SparkSession?</h2>
<p>The SparkSession is your <strong>entry point to all Spark functionality</strong>. Every PySpark program starts by creating one. Think of it as opening a connection to the Spark engine.</p>
<p>Before Spark 2.0, you had to create separate contexts (SparkContext, SQLContext, HiveContext). Now, SparkSession unifies all of these into a single object.</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">graph TD</span></span>

<h2 id="stopping-a-sparksession">Stopping a SparkSession</h2>

<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">stop</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Not calling <code>spark.stop()</code>.</strong> This leaves Spark processes running in the background, consuming memory and ports. Always stop when done.</li>
<li><strong>Setting master in production code.</strong> The cluster manager should set the master, not your code. Only use <code>.master("local[*]")</code> during development. In production, submit with <code>spark-submit --master yarn</code>.</li>
<li><strong>Creating multiple SparkSessions.</strong> Each session consumes resources. Use <code>getOrCreate()</code> to avoid duplicates.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>SparkSession is the single entry point to all Spark functionality</li>
<li>Use the builder pattern to configure before creating</li>
<li><code>getOrCreate()</code> reuses existing sessions</li>
<li>Always set <code>appName</code> for identification in the Spark UI</li>
<li>Use <code>local[*]</code> as master during development</li>
<li>Always call <code>spark.stop()</code> when finished</li>
</ul>
