<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Duplicate column names after join.</strong> If both tables have a column with the same name (other than the join key), you'll get ambiguous references. Use <code>on="column"</code> syntax (which deduplicates automatically) instead of <code>left["col"] == right["col"]</code> syntax (which keeps both).</li>
<li><strong>Using cross join accidentally.</strong> If you write <code>orders.join(customers)</code> without specifying <code>on</code>, PySpark does a cross join — 6 × 5 = 30 rows instead of the 5 you expected. Always specify the join key.</li>
<li><strong>Not considering the shuffle cost.</strong> Every join shuffles data across the cluster — both tables get repartitioned by the join key. On large tables, this is expensive. In Lesson 20 (Shuffles) and Lesson 25 (Broadcast Joins), we'll learn how to make joins faster.</li>
<li><strong>Using inner join when you should use left join.</strong> Inner join silently drops rows that don't match. If you have 1 million orders and 999,990 have matching customers, inner join quietly drops 10 orders. Use left join + null check if you need to detect these.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li><strong>Inner join</strong> — only matching rows. Use when you only want complete data.</li>
<li><strong>Left join</strong> — all left rows + matching right. Use for enrichment from a lookup table.</li>
<li><strong>Right join</strong> — all right rows + matching left. Rarely used; flip to a left join instead.</li>
<li><strong>Full outer join</strong> — all rows from both sides. Use when you need the complete picture.</li>
<li><strong>Anti join</strong> — left rows with no right match. Use for finding orphans and missing data.</li>
<li><strong>Cross join</strong> — every combination. Use sparingly and intentionally.</li>
<li>Always specify the <code>on</code> parameter to avoid accidental cross joins.</li>
<li>Joins trigger shuffles — we'll optimize this in Module 4.</li>
</ul>
