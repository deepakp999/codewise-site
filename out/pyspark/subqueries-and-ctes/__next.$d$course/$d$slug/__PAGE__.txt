<h2 id="subqueries-in-where">Subqueries in WHERE</h2>
<p>The most common use: filter based on a value computed from another query.</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Find orders above the average order amount</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT order_id, product, amount</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    FROM orders</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WHERE amount > (SELECT AVG(amount) FROM orders)</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ORDER BY amount DESC</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">show</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>

<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">show</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>
<div data-cw-section="output-block"><h3 id="expected-output-2">Expected Output</h3>

| name|   city|
+-----+-------+
|Diana|Chennai|

</code></pre></div>
<h2 id="subqueries-in-from-derived-tables">Subqueries in FROM (Derived Tables)</h2>
<p>Use a subquery as a temporary table inside FROM:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Revenue per customer, then filter to top spenders</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT name, total_spent</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    FROM (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT customer_id, SUM(amount) as total_spent</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        FROM orders</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        GROUP BY customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ) AS customer_totals</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    JOIN customers ON customer_totals.customer_id = customers.customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WHERE total_spent > 1000</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ORDER BY total_spent DESC</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">show</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>

<h2 id="ctes-the-clean-alternative-with-clause">CTEs: The Clean Alternative (WITH Clause)</h2>
<p>CTEs (Common Table Expressions) do the same thing as derived tables, but are much more readable:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WITH customer_totals AS (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT customer_id, SUM(amount) as total_spent, COUNT(*) as order_count</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        FROM orders</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        GROUP BY customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    )</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT c.name, c.city, ct.total_spent, ct.order_count</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    FROM customer_totals ct</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    JOIN customers c ON ct.customer_id = c.customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WHERE ct.total_spent > 500</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ORDER BY ct.total_spent DESC</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">show</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>

<pre data-cw-output="true"><code>+-------+---------+-----------+-----------+
|   name|     city|total_spent|order_count|
+-------+---------+-----------+-----------+
|    Bob|    Delhi|    1699.98|          2|
|  Alice|   Mumbai|    1479.97|          3|

<h3 id="multiple-ctes">Multiple CTEs</h3>
<p>You can define several CTEs, each building on the previous:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WITH monthly_revenue AS (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT </span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            SUBSTRING(order_date, 1, 7) as month,</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            SUM(amount) as revenue,</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            COUNT(*) as order_count</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        FROM orders</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        GROUP BY SUBSTRING(order_date, 1, 7)</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ),</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ranked_months AS (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT </span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            month,</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            revenue,</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            order_count,</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">            RANK() OVER (ORDER BY revenue DESC) as revenue_rank</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        FROM monthly_revenue</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    )</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT * FROM ranked_months</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ORDER BY month</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">show</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">()</span></span></code></pre>

|  month|revenue|order_count|revenue_rank|

<p>Each CTE is defined once and can be referenced by the CTEs that follow it or by the final query. This is much cleaner than nested subqueries.</p>

<p>Add a computed value from another query as a column:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT </span></span>

<h2 id="ctes-vs-subqueries-vs-multiple-views">CTEs vs Subqueries vs Multiple Views</h2>
<p>All three achieve the same result. Here's when to use each:</p>
<p><strong>CTEs (WITH clause):</strong> Best for complex queries within a single SQL statement. Self-contained, readable, no side effects.</p>
<p><strong>Subqueries:</strong> Fine for simple, one-off filtering. Gets unreadable when nested more than 2 levels deep.</p>
<p><strong>Multiple views (createOrReplaceTempView):</strong> Best when different parts of your pipeline need to access intermediate results independently, or when mixing SQL and DataFrame API.</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Same logic, three styles:</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Style 1: Nested subquery (hard to read)</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT name, total FROM (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT customer_id, SUM(amount) as total FROM orders GROUP BY customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    ) t JOIN customers c ON t.customer_id = c.customer_id WHERE total > 1000</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">)</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Style 2: CTE (readable, self-contained)</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    WITH totals AS (</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">        SELECT customer_id, SUM(amount) as total FROM orders GROUP BY customer_id</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    )</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">    SELECT name, total FROM totals JOIN customers USING(customer_id) WHERE total > 1000</span></span>
<span class="line"><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"""</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">)</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic"># Style 3: Multiple views (reusable)</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"SELECT customer_id, SUM(amount) as total FROM orders GROUP BY customer_id"</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">) \</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">    .</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">createOrReplaceTempView</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"totals"</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">)</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">spark.</span><span style="--shiki-light:#24292E;--shiki-dark:#61AFEF">sql</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379">"SELECT name, total FROM totals JOIN customers USING(customer_id) WHERE total > 1000"</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">)</span></span></code></pre>
<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Using <code>NOT IN</code> with a subquery that might return null.</strong> If the subquery returns any null values, <code>NOT IN</code> returns no results at all. Use <code>NOT EXISTS</code> instead, or add <code>WHERE column IS NOT NULL</code> to the subquery.</li>
<li><strong>Over-nesting subqueries.</strong> If you have more than 2 levels of nesting, switch to CTEs. <code>SELECT * FROM (SELECT * FROM (SELECT * FROM ...))</code> is a maintenance nightmare.</li>
<li><strong>Recomputing the same subquery.</strong> If you reference the same subquery in multiple places within a SQL statement, use a CTE — it's defined once and referenced by name. Spark's optimizer may or may not cache repeated subqueries, but CTEs make your intent clear.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Subqueries work in WHERE (filtering), FROM (derived tables), and SELECT (scalar values).</li>
<li>CTEs (WITH clause) are the readable alternative to nested subqueries — use them for any complex query.</li>
<li>Multiple CTEs can chain together, each building on the previous one.</li>
<li>Use <code>NOT EXISTS</code> instead of <code>NOT IN</code> when the subquery might contain nulls.</li>
<li>CTEs, subqueries, and views all produce the same execution plan — choose based on readability.</li>
</ul>
