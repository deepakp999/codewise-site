1b:T5570,<h1 id="enhancements--user-exits-badis-and-the-enhancement-framework">Enhancements — User Exits, BADIs, and the Enhancement Framework</h1>
<div data-cw-section="learn-box"><h2 id="what-youll-learn">What You'll Learn</h2>
<ul>
<li>Why you never modify SAP standard code</li>
<li>User exits and customer exits (legacy)</li>
<li>BADIs — Business Add-Ins (modern)</li>
<li>The Enhancement Framework (newest)</li>
<li>How to find the right enhancement point</li>
</ul>
</div><h2 id="the-golden-rule-never-modify-standard-sap-code">The Golden Rule: Never Modify Standard SAP Code</h2>
<p>SAP delivers millions of lines of standard code. When you upgrade SAP, all this code is replaced with the new version. If you modified standard code, your changes are overwritten. If you skip the modification during upgrade, you miss SAP's bug fixes and new features.</p>
<p><strong>Enhancements solve this:</strong> They provide predefined hook points in standard code where you can insert your custom logic — without touching SAP's code. When SAP upgrades, your enhancements survive.</p>
<h2 id="evolution-of-sap-enhancements">Evolution of SAP Enhancements</h2>
<pre><code>1990s     User Exits (FORM-based, very limited)
1990s-00s Customer Exits (function module-based)
2000s     BADIs (object-oriented, flexible)
2006+     Enhancement Framework (implicit enhancements, BAdI new)
</code></pre>
<p>Each generation improved on the previous. You'll encounter all of them in existing SAP systems.</p>
<h2 id="customer-exits">Customer Exits</h2>
<p>Customer exits are empty function modules that SAP calls at specific points in standard transactions. You fill in the code:</p>
<h3 id="finding-customer-exits">Finding Customer Exits</h3>

<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Go to the transaction (e.g., VA01 - Create Sales Order)</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* System → Status → note the Program Name</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* In SE38, search the program for 'CALL CUSTOMER'</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Method 2: Use transaction SMOD/CMOD</span></span>

<p>Customer exits are simple but limited — SAP provides a fixed set of exit points, and you can't add new ones.</p>
<h2 id="badis--business-add-ins">BADIs — Business Add-Ins</h2>
<p>BADIs are the modern replacement for customer exits. They use OOP (interfaces and classes) and are more flexible:</p>
<h3 id="finding-badis">Finding BADIs</h3>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Method 1: Search in standard code for GET BADI / CALL BADI</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* In the debugger, set a breakpoint on CL_EXITHANDLER=>GET_INSTANCE</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Method 2: Use transaction SE18 (BADI Definition) / SE19 (BADI Implementation)</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Search by application component or name</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Method 3: In the debugger</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Set a breakpoint at the beginning of the transaction</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Search the code for 'GET BADI' or 'cl_exithandler'</span></span></code></pre>
<h3 id="implementing-a-badi">Implementing a BADI</h3>
<ol>

<li>Create a new implementation</li>
<li>Write your code in the interface methods</li>

<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">    LOOP AT</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ct_items </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">ASSIGNING</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> FIELD-SYMBOL</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">&#x3C;ls_item></span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">      IF</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75"> &#x3C;ls_item></span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">-delivery_date </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">IS</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> INITIAL</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">        " Set error</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">      ENDIF</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">    ENDLOOP</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">  ENDMETHOD</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">ENDCLASS</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span></code></pre>
<h3 id="new-badis-enhancement-framework">New BADIs (Enhancement Framework)</h3>
<p>Since NW 7.0, SAP introduced "new BADIs" with improved features:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Finding new BADIs</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Search standard code for: GET BADI lo_badi TYPE badi_name</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Then: CALL BADI lo_badi->method_name</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* Implementing via SE19:</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 1. Enter the Enhancement Spot name</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 2. Create Implementation</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 3. Write your code in the provided class</span></span></code></pre>
<p>New BADIs support filters (execute only for certain company codes), fallback implementations, and multiple implementations.</p>
<h2 id="enhancement-framework--implicit-enhancements">Enhancement Framework — Implicit Enhancements</h2>
<p>The Enhancement Framework allows you to add code at specific points in ANY standard program — even where SAP didn't provide explicit exit points:</p>
<h3 id="implicit-enhancement-points">Implicit Enhancement Points</h3>
<p>SAP automatically provides enhancement points at:</p>
<ul>
<li>Beginning and end of every program/include</li>
<li>Beginning and end of every FORM routine</li>
<li>Beginning and end of every function module/method</li>
<li>After certain ABAP statements</li>
</ul>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* To use an implicit enhancement:</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 1. Open the standard program in SE38 (display mode)</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 2. Edit → Enhancement Operations → Show Implicit Enhancement Options</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 3. Right-click on a green enhancement point</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 4. Create Enhancement Implementation</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* 5. Write your code</span></span></code></pre>
<h3 id="explicit-enhancement-points-and-sections">Explicit Enhancement Points and Sections</h3>
<p>SAP also provides explicit enhancement points in strategic locations:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">* In standard SAP code, you'll see:</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">ENHANCEMENT-POINT</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ep_name </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">SPOTS</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> spot_name.   </span><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" Insert code here</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">ENHANCEMENT-SECTION</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> es_name </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">SPOTS</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> spot_name.  </span><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" Replace code here</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">  " Standard code that can be replaced</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">END-ENHANCEMENT-SECTION</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span></code></pre>
<p>Enhancement points let you INSERT code. Enhancement sections let you REPLACE code.</p>
<h2 id="finding-the-right-enhancement">Finding the Right Enhancement</h2>
<p>Step-by-step approach:</p>
<ol>
<li><strong>Start with the transaction.</strong> What transaction are you enhancing? (VA01, ME21N, etc.)</li>
<li><strong>Find the program.</strong> System → Status shows the main program.</li>
<li><strong>Debug to find the location.</strong> Set breakpoints, step through, find where your logic should go.</li>
<li><strong>Search for existing BADIs.</strong> Look for <code>GET BADI</code> or <code>CALL BADI</code> near your target location.</li>
<li><strong>Check customer exits.</strong> Search for <code>CALL CUSTOMER-FUNCTION</code> in the program.</li>
<li><strong>Use implicit enhancements</strong> as a last resort if no BADI or exit exists.</li>
</ol>
<h2 id="enhancement-hierarchy--what-to-prefer">Enhancement Hierarchy — What to Prefer</h2>
<pre><code>Priority    Type                      Pros                        Cons
─────────   ────────────────────     ──────────────────          ──────────────
1st         New BADI (SE18/SE19)     OOP, filtered, upgrade-safe  May not exist everywhere
2nd         Classic BADI              OOP, widely available        Older interface
3rd         Customer Exit (CMOD)      Simple, stable               Limited locations
4th         Implicit Enhancement      Works anywhere               Can be fragile across upgrades
5th         Modification (NEVER)      Full flexibility             Breaks on upgrade
</code></pre>
<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Modifying standard code instead of using enhancements.</strong> This is the cardinal sin of SAP development. Modifications are overwritten during upgrades and require manual conflict resolution. Always use enhancements.</li>
<li><strong>Not checking if a BADI exists before using implicit enhancements.</strong> Implicit enhancements work but are more fragile. If SAP provides a BADI at the same location, use the BADI — it's the supported extension point.</li>
<li><strong>Putting too much logic in an enhancement.</strong> Enhancements should call your custom class or function module — keep the enhancement itself thin. This makes testing and debugging easier.</li>
<li><strong>Not documenting your enhancements.</strong> Future developers (including future you) need to know why an enhancement exists. Add clear comments explaining the business requirement.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Never modify standard SAP code — use enhancements instead.</li>
<li>BADIs (SE18/SE19) are the modern, preferred enhancement mechanism.</li>
<li>Customer exits (SMOD/CMOD) are older but still widely used — you'll maintain many existing ones.</li>
<li>The Enhancement Framework provides implicit enhancement points in every program — use as a last resort.</li>
<li>Finding the right enhancement point requires debugging the standard transaction.</li>
<li>Keep enhancement code thin — delegate to your own classes and function modules.</li>
</ul>
