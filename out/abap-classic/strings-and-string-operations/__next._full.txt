<p>ABAP has two string types (from Lesson 6):</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">DATA</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">: lv_fixed </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> TYPE</span><span style="--shiki-light:#005CC5;--shiki-dark:#ABB2BF"> c</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> LENGTH</span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66"> 20</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> VALUE</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> 'Hello'</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">,      </span><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" Fixed-length, space-padded</span></span>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Using <code>CONCATENATE</code> when string templates are cleaner.</strong> <code>|Hello { lv_name }|</code> is more readable than <code>CONCATENATE 'Hello' lv_name INTO result SEPARATED BY ' '</code>. Use string templates for modern ABAP.</li>
<li><strong>Forgetting that <code>condense</code> removes internal spaces too.</strong> If you have <code>'New  York'</code> (two spaces) and condense it, you get <code>'New York'</code> (one space). Sometimes that's not what you want.</li>
<li><strong>Off-by-one errors in substring offsets.</strong> ABAP string positions are zero-based: <code>'Hello'+0(1)</code> = <code>'H'</code>. This is the same as Python, but the syntax <code>+offset(length)</code> is unique to ABAP.</li>
<li><strong>Comparing strings without considering case.</strong> <code>'Hello' = 'hello'</code> is <strong>false</strong> in ABAP (case-sensitive). Use <code>to_upper()</code> on both sides, or use <code>CS</code> for case-insensitive containment checks.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Use <code>TYPE string</code> for general text, <code>TYPE c LENGTH n</code> for fixed-width SAP fields.</li>
<li>String templates (<code>|..{ expr }..|</code>) are ABAP's f-strings — use them for readable concatenation.</li>
<li><code>FIND</code> searches, <code>REPLACE</code> substitutes, <code>SPLIT</code> breaks apart, <code>condense</code> trims.</li>
<li>String positions are zero-based. <code>strlen()</code> returns the length excluding trailing spaces.</li>
<li><code>CS</code> does case-insensitive containment, <code>=</code> does case-sensitive exact comparison.</li>
<li>Modern ABAP functions (<code>to_upper</code>, <code>to_lower</code>, <code>substring</code>, <code>condense</code>) are cleaner than classic statements (<code>TRANSLATE</code>, <code>SHIFT</code>).</li>
</ul>
