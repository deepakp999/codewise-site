</div><h2 id="what-is-alv">What Is ALV?</h2>
<p>ALV (ABAP List Viewer) is SAP's standard framework for displaying tabular data. It provides:</p>
<ul>
<li>Sortable, filterable columns (users can sort by clicking headers)</li>
<li>Column reordering (drag and drop)</li>
<li>Subtotals and totals (automatic)</li>
<li>Export to Excel/CSV (built-in)</li>
<li>Print formatting (automatic)</li>
<li>Search within results (Ctrl+F)</li>
</ul>
<p>All of this comes for free — you just pass your internal table to the ALV function module.</p>

edit         → 'X' to make the column editable
emphasize    → 'C110' for color (C = color, 1 = color number, 1 = intensified, 0 = not inverse)
hotspot      → 'X' to make values clickable (like hyperlinks)

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Not matching fieldname exactly.</strong> The field catalog's <code>fieldname</code> must match the internal table field name exactly (case-insensitive but spelling must match). A mismatch causes the column to not appear.</li>
<li><strong>Using the function module version instead of OO.</strong> <code>REUSE_ALV_GRID_DISPLAY</code> works but is the older approach. Modern ABAP uses <code>CL_SALV_TABLE</code> (next lesson). Both work — REUSE is simpler for basic cases, CL_SALV is more flexible.</li>
<li><strong>Forgetting to build the field catalog.</strong> If you don't pass <code>it_fieldcat</code>, you must pass <code>i_structure_name</code> (the name of a dictionary structure). Without either, ALV doesn't know your columns.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>ALV provides sorting, filtering, export, and totals for free — one function call.</li>
<li>Field catalogs control column display: headers, width, position, totals, visibility.</li>
<li>Layout options add zebra stripes, auto-sizing, and window titles.</li>
<li>Sort with subtotals gives you grouped reports without writing aggregation code.</li>
<li>Events enable interactive features like double-click navigation.</li>
<li><code>REUSE_ALV_GRID_DISPLAY</code> is the function module approach. <code>CL_SALV_TABLE</code> is the OO approach (next lesson).</li>
</ul>
