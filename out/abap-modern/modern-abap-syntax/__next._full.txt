1b:Tf3bb,<h1 id="modern-abap-syntax--inline-declarations-and-expressions">Modern ABAP Syntax — Inline Declarations and Expressions</h1>
<div data-cw-section="learn-box"><h2 id="what-youll-learn">What You'll Learn</h2>
<ul>
<li>Inline declarations with <code>DATA()</code> and <code>FINAL()</code></li>
<li>String templates with <code>| |</code></li>
<li>Constructor operators: <code>VALUE</code>, <code>NEW</code>, <code>CONV</code>, <code>COND</code>, <code>SWITCH</code>, <code>REDUCE</code>, <code>FILTER</code></li>
<li>Modern internal table operations: <code>FOR</code>, <code>CORRESPONDING</code>, table expressions</li>
<li>Why modern syntax matters for CDS and RAP code</li>
</ul>
</div><h2 id="why-syntax-matters">Why Syntax Matters</h2>
<p>You might think: "It's just syntax — the logic is the same." True. But modern ABAP syntax is not cosmetic — it makes your code shorter, safer, and easier for the ATC to analyze. RAP-generated code uses modern syntax exclusively, so reading and writing it fluently is essential.</p>
<p>Let's convert TechMart code from Classic to Modern, side by side.</p>
<h2 id="inline-declarations">Inline Declarations</h2>
<p>Classic ABAP requires you to declare variables before using them:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" CLASSIC</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">DATA</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">: lv_name</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> TYPE</span><span style="--shiki-light:#005CC5;--shiki-dark:#ABB2BF"> string</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">,</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">      lt_products</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> TYPE TABLE OF</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ztm_product,</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">      ls_product</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> TYPE</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ztm_product.</span></span>
<span class="line"></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">SELECT</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> *</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> FROM</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ztm_product </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">INTO TABLE</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> lt_products.</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">READ TABLE</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> lt_products </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">INTO</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ls_product</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> INDEX</span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66"> 1</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">lv_name </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">=</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ls_product-name.</span></span></code></pre>
<p>Modern ABAP declares variables at the point of first use:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" MODERN</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">SELECT</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> *</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD"> FROM</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ztm_product </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">INTO TABLE</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> @</span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">DATA</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">lt_products</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">).</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">DATA</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">ls_product</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">) </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">=</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> lt_products[ </span><span style="--shiki-light:#005CC5;--shiki-dark:#D19A66">1</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ].</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">DATA</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">lv_name</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">) </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">=</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF"> ls_product-name.</span></span></code></pre>

<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" FINAL = immutable (like a constant, but computed at runtime)</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">FINAL</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">lv_pi</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">) </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">=</span><span style="--shiki-light:#032F62;--shiki-dark:#98C379"> '3.14159'</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">.</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">FINAL</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">(</span><span style="--shiki-light:#24292E;--shiki-dark:#E06C75">lv_count</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">) </span><span style="--shiki-light:#D73A49;--shiki-dark:#C678DD">=</span><span style="--shiki-light:#6F42C1;--shiki-dark:#61AFEF"> lines</span><span style="--shiki-light:#24292E;--shiki-dark:#ABB2BF">( lt_products ).</span></span>
<span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" lv_count = 99.  " ← This would cause a compilation error</span></span></code></pre>
<p><strong>Rule of thumb:</strong> Use <code>FINAL()</code> by default. Switch to <code>DATA()</code> only if you need to reassign the variable later.</p>

<p>Classic string handling was painful:</p>
<pre class="shiki shiki-themes github-light one-dark-pro" style="--shiki-light:#24292e;--shiki-dark:#abb2bf;--shiki-light-bg:#fff;--shiki-dark-bg:#282c34" tabindex="0"><code><span class="line"><span style="--shiki-light:#6A737D;--shiki-light-font-style:inherit;--shiki-dark:#7F848E;--shiki-dark-font-style:italic">" CLASSIC</span></span>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Overusing <code>DATA()</code> when <code>FINAL()</code> is better</strong> — If you won't reassign the variable, use <code>FINAL()</code>. It communicates intent and the compiler can optimize.</li>
<li><strong>Forgetting the <code>@</code> escape in ABAP SQL</strong> — In modern syntax, host variables in SQL need <code>@</code>: <code>SELECT * FROM table INTO @DATA(lt)</code>. Classic syntax didn't need it, but modern SQL does.</li>
<li><strong>Panicking about table expressions raising exceptions</strong> — <code>lt_products[ 1 ]</code> raises <code>CX_SY_ITAB_LINE_NOT_FOUND</code> if the table is empty. Use <code>VALUE #( lt_products[ 1 ] OPTIONAL )</code> for safe access, or check <code>line_exists()</code> first.</li>
<li><strong>Using MOVE-CORRESPONDING in new code</strong> — It still works, but <code>CORRESPONDING #()</code> is the modern way and supports MAPPING and EXCEPT clauses.</li>
<li><strong>Writing modern syntax inside Classic programs</strong> — Modern syntax works in both Classic and Cloud. But if you're writing new code, write it in ABAP Cloud classes, not SE38 reports.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Modern ABAP syntax is shorter, safer, and more expressive than Classic syntax. It's not optional — RAP and CDS tooling generate modern syntax, and you need to read/write it fluently.</li>
<li>Use <code>DATA()</code> and <code>FINAL()</code> for inline declarations. Prefer <code>FINAL()</code> when the value won't change.</li>
<li>String templates (<code>| |</code>) replace <code>CONCATENATE</code>. Constructor operators (<code>VALUE</code>, <code>COND</code>, <code>SWITCH</code>, <code>REDUCE</code>, <code>FILTER</code>, <code>CORRESPONDING</code>) replace dozens of lines of procedural code.</li>
<li>Table expressions (<code>lt[ 1 ]</code>, <code>lt[ key = val ]</code>) replace <code>READ TABLE</code>.</li>
<li>Learn the <code>@</code> escape for host variables in ABAP SQL — it's mandatory in modern syntax.</li>
</ul>
