3:T37ba,<h1 id="setting-up-adt-eclipse-for-abap-development">Setting Up ADT (Eclipse) for ABAP Development</h1>
<div data-cw-section="learn-box"><h2 id="what-youll-learn">What You'll Learn</h2>
<ul>
<li>How to install Eclipse IDE and ABAP Development Tools (ADT)</li>
<li>How to create a free SAP BTP ABAP Environment trial account</li>
<li>How to connect ADT to your cloud system</li>
<li>How to create your first ABAP Cloud project and package</li>
<li>Your first "Hello World" in ABAP Cloud</li>
</ul>
</div><h2 id="goodbye-se80-hello-eclipse">Goodbye SE80, Hello Eclipse</h2>
<p>If you've been using SE80 your entire ABAP career, this lesson is a significant shift. Eclipse with ADT is not just a different editor — it's a different way of working. You'll have code completion, inline error checking, refactoring tools, integrated testing, and the ability to work on multiple objects simultaneously in tabs.</p>
<p>Think of the shift like this: SE80 is a flip phone. It makes calls, it sends texts, it works. Eclipse ADT is a smartphone — same core functions, but with a modern interface that makes you dramatically more productive once you get past the learning curve.</p>
<h2 id="step-1--install-eclipse">Step 1 — Install Eclipse</h2>
<p>Download Eclipse IDE for Java Developers (yes, Java — ADT runs as an Eclipse plugin):</p>
<ol>
<li>Go to <code>https://www.eclipse.org/downloads/</code></li>
<li>Download <strong>Eclipse IDE for Java Developers</strong> (latest release)</li>
<li>Install it — accept the defaults</li>
<li>Launch Eclipse and choose a workspace directory (e.g., <code>C:\eclipse-workspace\abap</code>)</li>
</ol>
<p><strong>Important:</strong> Use the "Java Developers" package, not "Enterprise Java" or "C/C++". ADT is compatible with the Java Developers package.</p>
<h2 id="step-2--install-abap-development-tools-adt">Step 2 — Install ABAP Development Tools (ADT)</h2>
<p>ADT is an Eclipse plugin provided by SAP:</p>
<ol>
<li>In Eclipse, go to <strong>Help → Install New Software</strong></li>
<li>Click <strong>Add</strong> and enter:
<ul>
<li>Name: <code>ABAP Development Tools</code></li>
<li>URL: <code>https://tools.hana.ondemand.com/latest</code></li>
</ul>
</li>
<li>Check <strong>ABAP Development Tools</strong> from the list</li>
<li>Click <strong>Next</strong>, accept the license, and finish the installation</li>
<li>Restart Eclipse when prompted</li>
</ol>
<p>After restart, you should see ABAP-specific perspectives and menu options.</p>
<div data-cw-section="output-block"><h3 id="expected-output-adt-installed-successfully">Expected Output (ADT Installed Successfully)</h3>
<pre data-cw-output="true"><code>Eclipse Menu Bar now shows:
  File | Edit | Navigate | Search | Project | Run | ABAP | Window | Help

ABAP Perspective available:
  Window → Perspective → Open Perspective → Other → ABAP
</code></pre></div>
<h2 id="step-3--create-a-sap-btp-abap-environment-trial">Step 3 — Create a SAP BTP ABAP Environment Trial</h2>
<p>SAP provides a free trial system — no cost, no credit card:</p>
<ol>
<li>Go to <code>https://www.sap.com/products/technology-platform/trial.html</code></li>
<li>Create a SAP Universal ID (or log in if you have one)</li>
<li>Activate the <strong>SAP BTP Trial</strong> in your preferred region</li>
<li>From the BTP cockpit, navigate to <strong>Instances and Subscriptions</strong></li>
<li>Create an instance of <strong>SAP BTP, ABAP Environment</strong> (trial plan)</li>
<li>Wait for provisioning (~10 minutes)</li>
</ol>
<p>Once provisioned, you'll see a service key with connection details.</p>
<p><strong>Note:</strong> The trial has limitations (storage, runtime quotas), but it's more than enough for this entire course. TechMart's training environment uses the same trial system.</p>
<h2 id="step-4--connect-adt-to-your-btp-system">Step 4 — Connect ADT to Your BTP System</h2>
<ol>
<li>In Eclipse, switch to the <strong>ABAP Perspective</strong> (Window → Perspective → Open Perspective → ABAP)</li>
<li>In the Project Explorer, right-click → <strong>New → ABAP Cloud Project</strong></li>
<li>Select <strong>SAP BTP ABAP Environment</strong></li>
<li>Enter your service key or use the <strong>SAP Logon Service URL</strong> from the BTP cockpit</li>
<li>Log in with your SAP Universal ID</li>
<li>Name your project (e.g., <code>TECHMART_CLOUD</code>)</li>
<li>Click <strong>Finish</strong></li>
</ol>
<p>You should now see the system in your Project Explorer with expandable nodes for packages, dictionary objects, and more.</p>

<pre data-cw-output="true"><code>Project Explorer:
  ▼ TECHMART_CLOUD [your-system-id]
    ▼ Favorite Packages

      ▼ Core Data Services

<h2 id="step-5--create-your-package">Step 5 — Create Your Package</h2>
<p>Every object in ABAP Cloud lives in a package. Let's create TechMart's development package:</p>
<ol>
<li>Right-click your project → <strong>New → ABAP Package</strong></li>
<li>Enter:
<ul>
<li>Name: <code>ZTECHMART_MODERN</code></li>
<li>Description: <code>TechMart Modern ABAP Development</code></li>
<li>Superpackage: <code>ZLOCAL</code> (for local development on trial)</li>
</ul>
</li>
<li>Click <strong>Next</strong>, select a transport request (or create a new one)</li>
<li>Click <strong>Finish</strong></li>
</ol>
<pre><code>Project Explorer:
  ▼ TECHMART_CLOUD
    ▼ Favorite Packages
      ▼ ZTECHMART_MODERN
        (empty — we'll add objects starting next lesson)
</code></pre>
<h2 id="step-6--your-first-abap-cloud-program">Step 6 — Your First ABAP Cloud Program</h2>
<p>Let's write a simple class to confirm everything works:</p>
<ol>
<li>Right-click <code>ZTECHMART_MODERN</code> → <strong>New → ABAP Class</strong></li>
<li>Enter:
<ul>
<li>Name: <code>ZCL_TM_HELLO_CLOUD</code></li>
<li>Description: <code>TechMart Hello Cloud</code></li>
<li>Add interface: <code>IF_OO_ADT_CLASSRUN</code></li>
</ul>
</li>
<li>Click <strong>Next</strong> → select transport → <strong>Finish</strong></li>
</ol>
<p>The <code>IF_OO_ADT_CLASSRUN</code> interface lets you run a class directly from ADT — it's the ABAP Cloud equivalent of a Classic report program.</p>

<p>Notice what's different from Classic ABAP:</p>
<ul>
<li>No <code>REPORT</code> statement — we use a class, not a program</li>
<li>No <code>WRITE</code> statement — we use <code>out->write()</code></li>
<li>String templates with <code>| |</code> instead of concatenation</li>
<li><code>cl_abap_context_info</code> instead of <code>sy-datum</code> and <code>sy-uname</code> (those aren't available in ABAP Cloud)</li>
</ul>

<div data-cw-section="mistake-card"><h2 id="common-mistakes">Common Mistakes</h2>
<ul>
<li><strong>Installing the wrong Eclipse package</strong> — The "Eclipse IDE for Enterprise Java and Web Developers" has conflicts with ADT. Use "Eclipse IDE for Java Developers."</li>
<li><strong>Not switching to ABAP Perspective</strong> — ADT features only appear in the ABAP perspective. If you don't see ABAP options, check Window → Perspective.</li>
<li><strong>Using <code>sy-</code> system fields in ABAP Cloud</strong> — <code>SY-DATUM</code>, <code>SY-UNAME</code>, <code>SY-SUBRC</code> after SQL are not available. Use <code>cl_abap_context_info</code> for system info and inline error handling for SQL.</li>
<li><strong>Creating objects in $TMP</strong> — <code>$TMP</code> is for local throwaway objects. Use a proper Z-package for anything you want to keep.</li>
<li><strong>Expecting SAP GUI transactions to work</strong> — SE11, SE37, SE80 — none of these are available in the BTP trial. Everything happens in ADT.</li>
</ul>
</div><h2 id="key-takeaways">Key Takeaways</h2>
<ul>
<li>Eclipse with ADT is the mandatory IDE for ABAP Cloud development. SE80 cannot create or edit cloud objects.</li>
<li>SAP BTP ABAP Environment trial gives you a free cloud system for learning — no cost, no credit card.</li>
<li>In ABAP Cloud, everything is a class. The <code>IF_OO_ADT_CLASSRUN</code> interface replaces classic report programs for console output.</li>
<li>Learn Ctrl+Shift+A, Ctrl+Click, and F2 immediately — they'll make you productive in ADT fast.</li>
<li>Classic system fields like <code>sy-datum</code> are replaced by <code>cl_abap_context_info</code> methods.</li>
</ul>
